Moveable on-screen timer for Broker stim duration and cooldown.

[b]Mod Settings / Commands:[/b]
[spoiler]
[b]General[/b]
- Track Standard Stims
- Font Size
- Icon Size
- Show Decimals
- Link All Positions
- Shared Position (Icon Position X/Y, Text Position X/Y)

[b]Ready[/b]
- Ready Color
- Icon Position X/Y
- Show Icon

[b]Active[/b]
- Active Color
- Icon Position X/Y
- Text Position X/Y
- Show Icon
- Show Timer

[b]Cooldown[/b]
- Cooldown Color
- Icon Position X/Y
- Text Position X/Y
- Show Icon
- Show Timer
[/spoiler]
